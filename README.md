# Petal Meadow

A to-do list where finished tasks feed blind-box pets. Each pet has a purpose (a day, a week, or a focus area) and its own growth goal. Grown-up pets move into the Meadow, and the Collection tracks every species found.

- `src/app.html` is the app.
- `tools/build.sh` builds `docs/`, the installable web app (served by GitHub Pages).
- `tools/icons.js` redraws the app icons (needs Playwright).

Data is stored on the device (browser storage).
